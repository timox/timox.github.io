Modèle hiérarchique
Ssir_strategie2 (Stratégie)
└── Ssir_programmes (Programme) 1:n
    └── Mission (groupe de tâches) 1:n
        └── Ssir_principale_task (Tâche) 1:n
            ├── nature_activite (WHY)
            ├── etape_code (WHERE)
            └── genre_action (HOW)

Les missions regroupent des tâches partageant le même mission_code. Chaque mission appartient à un programme via programme_id.

Vues à créer manuellement

L'API Grist ne permet pas de créer des vues automatiquement. Voici les vues recommandées :

  1. Page "Kanban" : Widget Custom → URL = index.html
  2. Page "Graphe Tâches" : Widget Custom → URL = taches.html
  3. Page "Par Nature" : Table groupée par nature_activite
  4. Page "Par Étape" : Table groupée par etape_code
  5. Page "Matrice" : Summary table groupée par nature_activite + etape_code
